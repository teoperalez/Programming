Issue 01 — “Hot Loops & Quiet Rooms” By Teo Peralez For Hire · teoperalez@gmail.com
Cover Story · Engineering profile

A frontend that actually moves, written by the engineer who built it.

I make interfaces for systems that move data really fast. Speedrun overlays read live emulator memory at 600 hertz. A poker solver runs Monte-Carlo equity in a browser tab. A twelve-step video pipeline stitches large language models into a Final Cut Pro XML, and a Rust emulator fork plays the result back, frame-accurate.

What ties it together is a refusal to treat the front end as decoration. The bar that creeps from green to red on a Pokémon overlay is a debounced state machine over a memory address. The pretty card you’ll see further in the issue is a CSS grid wrapped around a 7-card poker evaluator. The pixels are the product — but the data behind them is the work.

This is the first issue. Twenty-six dispatches follow, three of them interactive. Find the specimen page; play with the numbers. If the work fits the room you’re hiring for, the byline at the bottom is the way to reach me.

I want a frontend role where the data flying across the screen actually means something — live emulator state, solver output, AI pipelines, telemetry.

Cover · Overlay tooling

RBY / GSC / RSE NewLayout

Three Electron-and-React speedrun overlays — one per Pokémon generation — sharing a damage calculator, OBS chapter automation, and a trainer-mapping logger. Built portable for Windows, signed for macOS, distributed by a GitHub Actions release workflow.

The Gen 2 build ships the full damage calc: weather, Reflect / Light Screen, burn, badges, STAB, type effectiveness, semi-invulnerable double damage, Hidden Power / Return / Frustration variable power. The runner sees their next turn before the next turn happens.

RBY-GameHook

A WPF host plus WebAPI, both built as single-file self-contained executables, reading the PokeAByte shared-memory protocol at up to 600 Hz. Auto-updates from an XML feed I host at teoperalez.com/gamehook/, refreshed by the release pipeline.

Pipeline · AI

IRLPC Hyperframes

A twelve-step video pipeline. Whisper transcribes, GPT-4o-mini classifies A-roll versus B-roll, Claude Sonnet writes the skeleton plan, an Express approval gate on :5173 lets a human accept each clip, FFmpeg renders the segments, and a custom builder emits FCPXML 1.11 for Resolve.

Systems · Rust

AhShuckie

A hard fork of SnowyMouse/supershuckie. Keeps the deterministic replay format and shared-memory protocol; adds programmatic start/stop recording endpoints so a run can be auto-captured when the overlay sees setMyPokemon().

Rust · GPL-3.0:30158 · :55356
Solver

PokerSolver

An evolving Hold’em solver. The current build maps strategy outputs in PioSolver-style trees, with a scheduler designed to run background solves across every flop, turn and river for selected ranges, so the database of best lines fills in while the desk is asleep.

The interactive specimen below uses the same 7-card evaluator, simplified for the browser — drop two hands in, let it run a Monte-Carlo loop for a few seconds, watch the equity converge.
